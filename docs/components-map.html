The loops

LOOP 1 · Research moreGray-band company: up to 3 extra same-site pages, each with a logged reason, then re-scored.
LOOP 2 · Fix the draftValidator fails: one regeneration with the failures, else rejected_draft. Every human edit is re-validated.
LOOP 3 · Follow-upsAfter N days, in the same thread, until the prospect replies, unsubscribes or bounces.
LOOP 4 · SuppressionUnsubscribes, bounces and complaints join the suppression list, checked before every send.
